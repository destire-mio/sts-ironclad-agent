# 原版接入基础验证（2026-09-28）

本轮按缩小后的范围工作：补齐状态比较，验证特殊随机源的读档恢复，用冻结方案 C 做 3 个自然开局通路检查。完成终局 3 局；本报告不计算胜率，不提供 20 局统计。

方案 C 按会话中的 `sims32+boss12+rest+reuse+svsel+svcard` 执行：父网络 + 冻结 P300 多关价值表，单轮普通搜索 32,000，单轮 Boss 搜索 384,000，整场累计可以更高，复用搜索树。沿用 `runs/live-runtime-full-20260927-v7/`，没有更新策略、训练数据或规则引擎。单个模拟器决策进程。

执行环境是本机原版 JAR 的隔离 Java 逻辑实例，包含 BaseMod、CommunicationMod、SpireLabLogic 和状态审计模组，采用固定逻辑帧。它不是无 Mod 图形客户端录像。游戏文件、存档和本地实例留在 runs/，不作为分发物。

## 战后、奖励和整局状态

状态比较抽到 `steam/live_state.py`，不执行网络评分、价值表规则或搜索。每次先比较预测与原版，再导入原版状态，避免用已同步的状态冒充预测。新增种子、难度、幕数、楼层、界面、稀有牌概率修正和药水掉落修正；沿用血量、金币、牌组、遗物计数、药水、钥匙、游戏 RNG、地图和奖励检查。奖励界面不同会记录差异，不再跳过奖励比较。

固定原版夹具覆盖涅奥、首战、战后回血、奖励生成、金币领取、选牌和返回地图，共 25 条原版命令、6 个检查边界通过。7 个负例覆盖奖励金币、奖励牌升级、战后血量、楼层、药水概率、错误界面和剩余遗物池，均被检出。另通过原版 COMPLETE 界面继续、第四幕首张地图进入休息处和心脏节点存在的回归；缓存计划的血量根状态被改动时会被拒绝。该检查不调用策略选择。

原版命令重放新增比较剩余遗物池、事件/怪物/Boss 列表、奖励、地图和选择状态。首局 143 条命令的规则字段重放通过；16 条 RNG 的连续一致性没有通过，85 个观察点存在 MathUtils 差异。从第 59 条命令开始出现该差异，未将它隐藏在规则通过结果中。跨 JVM 的卡牌 UUID、全部私有字段和逐帧画面不在当前重放保证内。

## 特殊随机源与读档

这里的两个特殊源是 `MathUtils.random`（libGDX 通用源，xorshift128plus）和 `Collections.r`（java.util.Random，LCG48，供无显式 RNG 的 Collections.shuffle 使用）。记录其内部状态和 Gaussian 缓存。普通存档的 RNG 计数不能代替这份记录。

通过原版自然首战 autosave 执行读档：自然状态和注入缓存值两种诊断各检查 16 条 RNG、战斗状态、240 个后续随机输出、12 次真实 Collections.shuffle，以及读档后重复结束回合的结果。共执行 4 次诊断读档，均不计入自然局。检查点保存于 `runs/live-foundation-sl-20260928-v3/`。

恢复前验证种子、幕数、楼层、16 条流的名称、算法与字段；错误请求被拒绝，原状态保持一致。恢复过程出错会回退 RNG。未初始化的 Collections.r 可以恢复为未初始化，但首次无种子初始化的未来输出不能据此预测。整个测试使用固定原版动作前缀，不调用父网络或价值表。

读档后的状态恢复通过，不代表其后每一帧消耗相同数量的通用随机数。当前动作日志支持规则重放，不能替代逐帧视频。

## 自然开局通路检查

种子 5100000002 的首次尝试在第 50 层打赢觉醒者后出现接入故障：原版返回 COMPLETE 界面，桥接层没有执行继续。修复后重跑同一种子。另按原版 bossList 在进入房间时移除当前 Boss 的语义，导入剩余 Boss 状态，防止第二场战斗结束后模拟器重复安排 Boss。此修复属于状态/界面适配，不改策略。第 50 层故障后的一次自然重试穿过双 Boss 到达第四幕，因首张地图保留上一幕 VictoryRoom 而触发导入故障。修复时统一首张地图的房间生命周期处理，并补上原版地图接口省略的心脏节点。故障记录保留，不记为败局；后续复用同种子同 runtime 的保存计划，先逐动作重放并核对规则状态，再继续新的决策。前缀重放不新增独立样本，故障重启与战斗 SL 分开记录。

## 剩余边界与后续

已观察的分歧包括非战斗楼层 RNG 重置时点、虚无牌消耗顺序或同牌身份关系、商店返回界面，以及 Boss 战后 native 自动跨房间而原版需要继续按钮的阶段差异。后者的原始比较保留，但不能把尚未点击继续时的跨幕回血差解释为真实血量损失。本轮没有做分歧对胜负的因果实验。

模拟器没有逐步预测 MathUtils.random、Collections.r 和原版持久 mapRng；部分事件、怪物与卡牌私有字段仍缺少完整导入。事件/遗物池在原版重放中接受比较，尚未全部加入模拟器逐步预测比较。无差异记录不能解读为全部内存状态一致。

本轮不改变父网络、P300 价值表或战斗规则，因此没有由本轮基础改动产生的价值表条目重测清单。策略后续变化时，保留这些状态和读档检查，替换冻结策略输入即可。20 局评测继续搁置。

批次的当前入口在故障时返回退出码 2；历史首次故障批次曾返回 0，逐局 status 与 summary 的 faults 才是它的判定依据。此错误码缺陷在交付代码中修正。
