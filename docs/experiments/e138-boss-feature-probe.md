# E138：E134的选牌读出没有接入Boss遗物身份

使用原顺序16个不同fit家庭中，父遗物分支能到达选牌的既有状态。核对原生遗物列表与观测位置后，保持牌组、血量、候选和其他输入不变，分别设置22个拟合支持集内的Boss遗物标志。这是模型输入探针，没有运行相应反事实游戏，也没有使用胜负标签筛选状态。

352次扰动中，E134显式选牌特征变化0次；E128旧网络的居中候选特征与学习读出分数变化均为352次。16个枯木标志正对照均改变显式特征。原生状态/RNG保持不变。代码解释与实测一致：E134选牌上下文有牌组比例、腐化/黑暗之拥/无惧疼痛和枯木，没有Boss遗物身份。

这个缺口限制的是新学习读出能够表达的条件偏好。父动作加成仍可能通过父策略随遗物变化；真实遗物效果也可能改变其他状态字段，因此不能说整个策略完全看不到遗物。旧冻结表示已有这项输入响应，不能将E128失败解释为同一个缺口。E134结果仅排除了当时的粗粒度表示，不能排除带Boss条件的显式关系表示。

后续修正保持E134已有192维内容，给选牌追加“当前Boss遗物身份×已有候选属性”，遗物头的功能保持。以旧模型作为可复现的零增量对照，再用原fit家庭分组检验学习；不在历史留出上扫描属性或阈值。新增维度/参数的代价需要报告，响应检查不当作胜率提升。E137首卡学习与E136审核的冻结输入不改。
