# E137 条件学习设计：用已有早期选牌续局学习一次决策

启动前提是E136完整审核和主任务对来源、全部终局/父策略/RNG证明链的复核通过。本文件是条件设计，学习代码、正式登记和进程尚未启动；没有新增采样请求。

E134/E135的晚期两节点读出未获得跨家庭收益，且概率部署差别不足以解释失败。E131的既有pilot中，单改早期选牌有26个家庭存在胜路，父策略为16个，但这是事后范围结果。E136使用取消前保存的完整早期选牌阶段，允许用旧数据检验这部分是否能学会，无需补齐昂贵的后续遗物枚举。

使用原1536个fit家庭。模型复用冻结父网络和已实现的EarlyCardPolicy，只开放第一幕第一战最后一份选牌的头，change_relic=False，其他局外决策及战斗预算沿用父策略。拟合头读取父网络的192维表示并训练卡牌身份偏好；合法支持集和RMS仅从对应拟合家庭计算，父动作加成1，未知菜单回退父动作。完整心脏终局为目标；每张候选牌的标签对应固定父策略续局，不替换成最佳后续遗物，也不使用楼层奖励。

固定1000步Adam、学习率.03、L2 .001、梯度上限1。先按已有三折家庭哈希执行三个模型，所有同家庭的候选保持同折；记录每个家庭未参加对应模型拟合时的结果。跨折相对父策略需净增至少30/1536且配对描述性p<.05，才允许训练一个全fit最终模型并读取历史1024留出。没有参数网格、温度扫描或留出选检查点；跨折未过关则记录失败，不扩大采样。

全fit模型冻结后，历史留出仍要求净增至少20/1024且配对p<.05，覆盖所有可达真实状态的部署动作核对和原分母。若通过，再以原512个独立自然开发家庭检验完整NN/MCTS运行，要求净增至少10且p<.05、零故障、全部终局/RNG/局外动作审核和胜局新规划复现。源512父策略对照可复用其合格证明。这属于候选评估，不作为额外训练采样。

实施必须验证零头恢复父策略、只干预该次卡牌机会、禁用遗物头、未知选项回退、拟合/部署排序一致、保存加载相同、错误或缺失来源拒绝。没有完成这些检查前不启动优化器。E136原标签存储和E133关闭状态保持。

候选不会自动采用。历史fit/留出提供开发证据，最终验收仍需模型和策略冻结后1024个未用于训练或设计选择的家庭，至少512次完整A20心脏胜局。这次单次早期选牌尝试可能受到范围限制；若失败，按证据调整学习方法或干预范围，不把重新堆数据当作默认动作。
