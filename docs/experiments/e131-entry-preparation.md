# E131 执行入口与准备检查

状态：代码和回放预检完成；正式 128 家庭试验没有启动。设计与资源上限沿用 [E131 条件方案](e128-followup-analysis-plan.md)，父模型、引擎、128 家庭清单和接受门槛没有变化。

入口为 [`agent/heart_early_card_scope.py`](../../agent/heart_early_card_scope.py)。开发在 `sts-rl-agent-early-card-scope` 工作树进行，起点为 `1135fbc`；当前 E127/E128 的运行副本保持原样。实现复用现有分支执行器、自然动作回放、网络加载器和拥有进程组的启动器，没有增加战斗搜索、训练目标或神经网络结构。

## 执行过程

1. 从训练完成证明核对两臂的拟合、留出及需要执行的自然开发阶段。缺少证明、发生执行故障、有候选通过门槛、来源身份变化或主任务复盘记录不匹配时，拒绝启动。故障与候选没有过成绩门槛分开处理。
2. 从已登记的 128 个拟合家庭恢复第一幕第一场战斗后的最后一份选牌。每个候选使用同一父策略完成续局；原动作对照须复现来源，之后执行替代动作。这里仍包含没有出现干预节点的家庭。
3. 沿每条改牌后的真实路线寻找首幕 Boss 遗物节点。父策略选择、候选菜单、状态和 RNG 来自该分支；每个后继节点绑定所属种子和第一处动作。原动作对照通过后枚举遗物替代项。预算不足记为未完成，不能删除候选。
4. 对每条新轨迹做独立局外动作、终态和 RNG 核验，与同组旧范围的完整覆盖结果比较。每个“新范围能赢而旧范围全部所测组合都输”的家庭，按动作 bits 的字典序选一条获胜轨迹，从自然开局重新运行 NN/MCTS 并核对三钥匙、双 Boss、剑盾和心脏。
5. 只有完整数据与核验通过后生成范围报告和是否扩大数据的决定。事后获胜分支的存在不作为神经网络已经学会的证据。该入口没有优化器、模型采用或新种子验收操作。

采集与独立核验分别共享 4 小时、1 小时上限，阶段内部的对照和替代分支不能各自重置预算。执行器至多使用 8 个单线程工作者；沿用 300/360 秒单局/进程保护。现有启动器负责退出、超时及中断时清理所属子进程。

## 已测范围与缺口

- 17 个纯 Python 测试方法通过：小树的独立预期、提前死亡分母、分支各自的父策略选择、组合获救、缺失/重复/错接的节点、标签为空、数据角色、启动条件和来源绑定等。
- 3 个 C++ 模拟器回放测试方法通过：读取拟合集清单中的前四个固定种子，不按结局替换；检查第一战节点、后继父策略遗物节点、合法卡牌动作消耗机会、整条父策略路线复现和错误干预被拒绝。此处的 native 指模拟器扩展，不是原版 Java 游戏。
- 对真实 E128 目录做一次只读启动检查，因缺少 `training-execution.json` 被拒绝，E131 执行目录没有创建。这不表示当前采样进程停止；采样观察由 Luna 负责。
- 扩展测试暴露了 macOS `/var` 和 `/private/var` 指向同一文件时的错误拒绝。入口改为比较解析符号链接后的路径；“同文件别名通过、不同来源文件拒绝”的对照通过，失败记录保留。

完整“改第一幕卡牌→新 Boss 遗物→终局”的新续局、工作者执行和新增获救局重规划，属于正式试验尚待执行的部分。以上检查不证明该策略提高胜率。准备证据与代码哈希见 [JSON 报告](e131-entry-preparation.json)；原始测试日志与失败记录留在本机的 E131 `implementation-checks` 目录。

## 后续启动

主任务在 E128 结束后分析完整报告，决定是否满足原条件。执行决定记录必须绑定训练/开发完成证明、来源与两阶段标签证明、原 E131 计划以及本入口代码 SHA256。该记录由主任务产生，不要求用户重复批准，也不能由采样观察任务自动生成。

`check` 检查相同的输入和主任务记录，返回准入结果；`start` 才创建独立运行副本并执行试验。通用调用形式如下，所有路径由本轮冻结记录提供：

```text
python3.12 agent/heart_early_card_scope.py check \
  --repository /absolute/path/to/sts-rl-agent-pr \
  --plan /absolute/path/to/E131/plan.json \
  --study /absolute/path/to/E128 \
  --review /absolute/path/to/E131/result-review.json
```

核对后将 `check` 改成 `start`。入口拒绝覆盖既有执行目录；过程失败保留原记录，不能把再次执行包装成首次完整试验。Luna 当前负责 E127/E128，本工作单不启动 E131。
