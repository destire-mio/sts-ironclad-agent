# E132：旧模型的分数由什么贡献

登记日期：2026-09-21。本次复用完成的 E89 模型和结局，拆解 E95 观察到的拟合／跨家庭差距。Luna 负责当前 E127/E128；本诊断不接替采样观察，不读取当前中途标签，不启动训练或新对局。

旧模型在选牌或选遗物时，把三部分相加：根据当前观察与候选得到的分数、每张牌或遗物的固定偏好、父策略原动作的 1 分加成。前两部分在原实验中共同学习。本次只在内存中拿掉其中一部分，观察这三个已保存模型的选择和结局变化。

| 对照 | 当前观察与候选的读出分数 | 固定身份偏好 | 父动作加成 |
|---|---|---|---|
| 父动作控制 | 0 | 0 | 1 |
| 原完整模型 | 保留 | 保留 | 1 |
| 固定偏好部分 | 0 | 保留 | 1 |
| 读出部分 | 保留 | 0 | 1 |

只使用 E89 联合头 L2=.001 的三份家庭划分，与当前 E128 的固定正则值相同；这组旧成绩在本次分析前已公开，因此结果属于事后诊断，不是候选选择或未见验收。每份模型在自己的拟合家庭和原留出折上评估。所有 1536 个家庭保留，包括没有到达决策点的失败；拟合出现次数 3072 是每个家庭出现两次，不能视为 3072 次独立游戏。

运行前冻结[协议](e132-readout-components-protocol.json)与[脚本](e132-readout-components.py)。完整模型必须逐项复现 E89 的全部留出选择、E95 的各折拟合／留出计数和随机策略期望；父动作控制必须恢复所有原动作。保留原候选范围、各折支持集、缩放、缺候选回退与平手规则。另用原始树的动作身份查找每个终局，不复用训练张量下标作为结果核对。源数据、运行代码及权重在执行前后核对哈希。资源限制为单线程、600 秒，没有优化器更新或 MCTS 调用。

这种拆分不能回答“单独训练固定偏好是否更好”。原权重是两部分共同学习的结果，删去一部分会改变另一部分工作的条件；读出使用的候选表示也包含牌或遗物身份，不能把“读出部分”理解成完全没有固定偏好。旧 E89 的引擎与当前 E121 不同，结果不能写成当前模型的胜率。

本诊断不改变 E128 采用门槛或 E131 执行条件。它只能为后续学习对照提供依据：是否需要在相同家庭、相同标签与更新预算上，区分固定身份偏好和状态相关决策；不能凭删分数后的成绩采用模型或追加一轮调参。

## 完成结果与下一轮的影响

脚本在 51.55 秒内完成，退出码 0。原完整模型复现全部旧留出选择、各折拟合／留出统计及随机策略期望；零分数组恢复父动作；独立字典解码匹配所有选中叶子。来源哈希保持一致。没有新对局、参数更新、外部标签留出／开发评估或模型采用。[完整聚合结果与证据哈希](e132-readout-components-result.json)。

| 使用的分数 | 拟合出现次数中的胜局 / 3072 | 原留出折胜局 / 1536 | 相对父策略新增 / 丢失胜局 |
|---|---:|---:|---:|
| 父动作控制 | 310 | 155 | 0 / 0 |
| 原完整模型 | 446 | 165 | 43 / 33 |
| 固定偏好部分 | 310 | 155 | 0 / 0 |
| 读出部分 | 438 | 164 | 42 / 33 |

去掉额外固定偏好，拟合胜局减少 8，留出胜局减少 1；留出中 45 个家庭选中的叶子发生变化，其中 3 个由胜变负、2 个由负变胜。这说明这组三份模型的拟合收益与跨家庭问题依赖读出部分，不能靠删除固定偏好消除。完整模型相对父策略的配对 p=.302，读出部分 p=.356，均未达到旧采用门槛。本次属于事后诊断，不能再把这些比较当作新一轮接受检验。

结果出来后检查六个固定偏好向量，遗物的最大分差为 .679～.923，选牌为 .168～.282，均低于父动作的 1 分加成。因此这些共同训练得到的固定偏好独立使用时，无法改变任何贪心选择。这个零变化有确定的打分原因，不能解释成“固定偏好已经训练到最优但没有价值”。这里去掉的是额外偏好，父模型包含的既有遗物策略仍在。报告中的 `stochastic_return` 是这些分数经过 softmax 后的期望；零分数组的 softmax 仍给替代动作概率，因此该字段不等于父策略贪心胜率，表中的胜局才对应部署选择。

对下一轮的决定是：不采用这两种删分数版本，不对旧权重追加缩放／阈值扫描。当前 E128 继续回答“独立家庭增加后，这种读出能否学到跨种子收益”；完整结果失败时，按 E131 原条件检查提前选牌是否带来新的可学范围。若后续需要比较简单策略与状态相关策略，须从各自拟合目标训练，并保留相同家庭划分与结局，不能拿本次删部件作为替代。本次没有增加新的必跑训练轮，也没有把“表示缺陷”或“数据不足”升级为确定根因。
