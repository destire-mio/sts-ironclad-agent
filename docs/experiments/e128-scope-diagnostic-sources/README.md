# E128 decision-scope diagnosis

Run after both model checkpoints, complete simulator labels and heldout live-choice verification. The script reconstructs every selected leaf and separates missed available wins from limitations of the two measured decisions. It does not fit models, sample games or require original-game evidence.

Historical E89 counts motivate the decomposition and are not new E121 results. New model outcomes remain unread until the registered completion gates pass. Per-family output stays local.
