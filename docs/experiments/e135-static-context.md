# E135：在既有拟合家庭中比较固定偏好与情境

问题来自 E134：新表示提高拟合胜局，却没有改善历史留出。E132 删除共同训练出的身份偏好时，其分数差小于父动作加成，不能回答单独训练固定偏好是否有效。E69 比较过单次遗物静态/神经模型，但父策略、标签和动作范围不同。本轮使用相同两节点联合目标与数据，分开训练两种策略，定位情境特征是否帮助跨家庭决策。

复用 E128 小组的 1,536 个完整 fit 家庭。按已有 E73-family-fold 哈希规则分三份，家庭内的所有遗物/选牌分支放在同一份。每次用两份拟合、在剩下一份检查；每个家庭有一条未参与对应模型拟合的选择。外部 1,024 留出、512 自然开发和未见验收不进入输入文件。

- 固定偏好组：训练选项身份分数，384 个情境权重从开始保持零。
- 情境组：独立重复 E134 的显式特征、选项偏好及训练规则。
- 每组做三次分组训练和一次完整 fit；合计八个固定 1,000 步训练，没有网格。完整情境模型必须重现 E134 的全部拟合选择。
- 两组使用相同家庭、全终局联合目标、.03 学习率、.001 L2、梯度上限 1、父动作加成、拟合支持集/RMS和未知菜单回退。固定偏好组参数更少，这是所比较的限制，不称为相同参数量。

报告每折拟合与留出、完整拟合、配对新增/丢失和实际训练耗时。模型权重冻结后读取对应折的验证结果，保存每折支持集与权重，独立解码选中叶子。两组不会因本次诊断自动进入外部评估或采用。折间共享训练家庭，配对 p 值是描述性诊断，不能当作独立验收。

四项前置测试通过，覆盖外部角色/额外状态拒绝、固定分数能更新且父策略与情境权重不更新、改变无关情境不影响固定分数、原生状态动作及 RNG 只读核对、关闭入口拒绝。原生验证使用原顺序前四个符合范围的既有 fit 家庭，不按胜负筛选。启动准备曾误列不存在且无依赖的 heart_processes.py，改为绑定实际 run_pipeline.py / run_collections.py 后启动；错误发生在优化器启动前，记录保留。

正式运行在 09:02 启动、09:03 完成，控制器与拟合进程退出 0、清理通过。八次拟合合计 8,000 步，优化器耗时 22.34 秒。全部模型保存/加载一致，父网络未更新；完整情境模型复现 E134 的全部拟合选择。完成后的独立复核重算每折支持集与拟合 RMS，重建全部选中终局和配对计数，未见异常。

分组结果中，固定偏好新增31／丢失35，情境新增46／丢失49。二者均无收益证据，不能采用或据此扩采。固定偏好的完整 fit 模型没有改变家庭动作；三个分组模型改变家庭数为352、324、0，偏好并不稳定。情境完整 fit 的增益消失于未参加该次拟合的家庭。

另做只读目标核对：按两阶段真实终局叶子独立计算概率选择的期望，并与训练张量结果比较，全部相符。跨折固定偏好期望130.88胜、情境147.22胜，父策略最高分选择149胜。分数是概率期望，不是新增游戏实测。训练与最高分部署的区别存在，但改为概率部署仍无收益证据，不能单凭这个区别指认根因。没有温度或阈值扫描。

下一步使用取消前保存完整的“第一张牌改选→固定父策略续局”阶段，建立独立数据定义和审核。文件存在不等于标签准入；须核对全部角色、候选、原动作对照、完整终局、局外父网络选择与状态/RNG。E133 后续遗物层和整项研究保持关闭，不把缺少后续遗物分支的树当成完整联合树。此步骤不采新游戏。
