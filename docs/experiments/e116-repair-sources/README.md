These files preserve the project's own local E116 verification scripts. They expect the recorded evidence-directory layout, a local game installation and the isolated original-game adapter; they are not standalone public runners. Game JARs, checkpoints and raw original traces are excluded.

The portable entry is `sim_patch/e116_bomb_instances.patch`, followed by the alignment CMake suite. Its C++ and Python snapshot regressions are in `sim_patch/alignment/tests/`. The completed scope and remaining limits are in `sim_patch/alignment/e116-bomb-instance-report.json`.
