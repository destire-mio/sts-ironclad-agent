# E143 / E144: learn across the complete run using existing routes

The previous first-card experiments fit their measured training possibilities but did not transfer between families. Their best measured first-card continuation contains281 wins out of1,536 families; this restricted action scope cannot support a50% development target. E143 keeps every noncombat decision in the existing6,144 audited E136 fit routes, including Neow, map, reward ordering, cards, events, potion decisions, shops, rest, selection and boss relics. One parent-control route per family begins at natural start; the other three routes begin at their changed first card. A changed future must not label decisions in the earlier common prefix. Recorded battles connect successive decisions without any new MCTS. Only the final transition receives the binary Heart outcome; there is no floor or health reward.

The5,339 features combine an allowlist of public observation fields, the mean legal-menu descriptor, the selected descriptor and menu size. Seed, RNG, future actions, terminal metadata, event scratch storage and hidden probabilities are excluded. Existing menu visibility rules apply. E143 replays all stored actions and verifies each terminal state/RNG before exporting the chronological sequences. Family data and compact indexes have separate files to bound controller memory.

E144 tests two learning signals on those same routes. The Monte Carlo arm gives every recorded action its terminal Heart label. The temporal arm uses a frozen snapshot of the current critic to compute backward targets, with lambda=.8: the last target is the terminal label; each earlier target is .2 times the value of the next recorded parent action plus .8 times the next target. Each snapshot stays fixed for2,000 updates. Both arms use the same10 passes, model initialization, original three family folds, sampling uniforms, optimizer and full-menu regularization. No validation-family target participates in a fold's fitting.

The model is a fully trainable5,339→128→64→1 SiLU network with691,841 parameters. Initial predictions are .1 for every action, preserving parent ties. Training samples a fit family and one of its four routes uniformly, with .25 probability of its first-card decision; remaining samples choose an available act and a non-root decision uniformly. BCE on the recorded-action target is combined with .05 cross entropy for that action across its whole legal menu. This discourages unsupported high values, without providing a reliability or optimality guarantee. Features are stored in separate sparse shared-state/menu and candidate tables; the first linear layer combines them without replicating the shared state per candidate.

The deployed critic chooses at every noncombat decision. Only action identities chosen somewhere in the model's fit families can replace its frozen parent; the parent remains eligible and wins exact ties. This permits several changes in one run, so existing single-intervention terminal labels cannot establish the new policy's success. Sparse training and dense deployment predictions/gradients, target boundary/isolation, loss arithmetic and source admission have controls. Complete natural-route controls recover the parent with constant values and reject altered choices, RNG or terminals.

After fitting, both arms must complete the same128 development families selected before outputs by the lowest `SHA256(E144-full-run:{seed})` among the original1,536 fit roles. Each uses its excluding-fold model. The unchanged combat settings are MCTS8,000, boss multiplier3 and256 replans. All outside choices, complete terminal/state/RNG replays and fresh NN/MCTS reruns of every winner must pass. Errors and timeouts are faults, never deaths. Each arm needs net+8 over the frozen parent and descriptive paired p<.025. These are bounded policy-validation games; none become new training labels.

A passing arm would be selected by net wins, then fewer parent wins lost, with an exact tie choosing Monte Carlo. Only then fit one complete1,536-family model with the same recipe and freeze it for the reserved512 natural-development families. That next gate requires net+20 and p<.05 plus full audits; no model is adopted automatically. Final acceptance remains a single frozen policy winning at least512 out of1,024 seed families unused in training or selection. Original-game parity is outside this experiment at the user's direction; Prismatic Shard is excluded.
