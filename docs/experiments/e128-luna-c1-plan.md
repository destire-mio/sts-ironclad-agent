## 检查任务

1. **顺序决策的目标。** 独立计算小型树的期望值，与冻结 `heart_relic_card_model.expected_returns` 比较。遗物概率为 `[0.6, 0.4]`，其后两处选牌概率分别为 `[0.2, 0.8]`、`[0.3, 0.7]`，对应终局结果为 `[1, 0]`、`[0, 1]`，期望值应为 `0.4`，而事后最优组合为 `1`。固定遗物选第二个时应为 `0.7`；固定两处选牌均选第一个时应为 `0.6`；两者同时固定时应为 `0`。这些值由概率树推出，不从待测函数生成。另覆盖无需后续选牌的终局分支、填充掩码及两头梯度方向。已有可靠同类检查可引用，新增测试聚焦缺口。
2. **分母和数据归属。** 从 T 的数据构造、损失、支持集合与缩放拟合调用链核对：早期死亡的固定前缀保留在独立种子分母；small 的 1536 个 fit 家族嵌套在 expanded 的 4608 个 fit 家族；fit 与共同 label holdout 1024、development 512 的归属互斥；支持集合、RMS 与参数梯度只取本臂 fit；同一种子的遗物/选牌分支不能作为独立种子重复计数。此项可用注册清单、家族 ID 和小型夹具检查，不读取未完成联合采样的胜负分布。
3. **部署与评价的一致性。** 核对训练采用当前两头概率的期望、部署采用实际可见状态下的选项评分；训练期望值不能作为部署胜率。检查双方最终检查点在共同 holdout 评分前冻结，缺失标签拒绝进入训练，未知完整选项集回退父策略。对每项给出源码位置、已有证据、补充用例或未覆盖边界。
