# E140/E141：用完整旧路线训练候选牌价值

E134/E135的显式读出、E137的首卡读出和E139的Boss条件修复没有通过各自筛选。本次检验可训练表示和旧路线里的后续状态，停止冻结读出的连续小变体，不扩大采样。

E140复用E136完成审核的1536个fit家庭、6144条首卡续局。每条保留干预的首卡节点，以及其后每幕至多8次实际选牌，按前缀位置哈希选取，不按成败筛选。所有状态和战斗动作重放，核对终态与RNG；没有MCTS重新规划。干预前的共同前缀不贴干预后的标签。未来实际行为和终局只作为标签与审核证据，不能进入输入。

输入是选牌前的公开状态与候选牌：血量、金币、幕／层、钥匙、当前Boss、地图、牌组及卡牌特殊数值、遗物身份与计数、药水和火焰位置，加候选牌身份、升级及特殊数值。输入白名单排除种子、RNG、前缀序号、未来行为、终局元数据、事件工作区和内部概率。共4100维。网络给候选牌预测固定父策略续局的心脏成功概率；不模拟未知未来，也不把获胜路线的每个动作当作因果最优。

E141比较两个同架构模型，4100→128→64→1，SiLU，可训练参数533249。全部层参与学习。root_only使用首卡的完整四选项标签；root_plus_later以一半概率使用首卡，一半使用该路线后续真实选牌。均匀抽家庭，再均匀抽首卡分支；后续按可用幕和保留状态均匀抽取，无后续状态时回到首卡。两组使用相同随机数序列选家庭和分支，不按路线长度或成功过采样。额外状态不增加独立种子数。

沿用原三折家庭哈希，同家庭全部分支和后续状态放在同折。两组每折2000步AdamW，批256、学习率.001、衰减.001、梯度上限1、固定初始种子，BCE拟合二元终局。取最后一步，参数不扫描，外部留出不参与。拟合支持集来自该折首卡菜单；未知菜单整份回退父策略。实际决策只接管第一幕第一战最后一份选牌，其余局外选择及MCTS预算沿用父策略。

验收看未参与对应折拟合家庭的选牌及真实终局，每臂需较父策略净增30／1536且描述性配对p<.025，再由主任务决定全量模型和历史留出准入。分类损失下降或拟合胜数不代替此门槛。两臂及候选间差值完整记录，不能只报优胜一组。真实状态部署核验覆盖合法菜单、原生卡牌身份、NumPy独立算分、保存加载、选中终局及查询不改状态/RNG。

4项数据前置检查和6项学习前置检查通过，包含16条既有续局重编码、错误来源／标签拒绝、层级抽样、表示梯度、四条完整父路线控制、非零模型改变首卡、范围外行为和未知菜单回退。E140持久日志控制器已启动；E141实现和固定协议完成，完整数据审核与主任务复核是训练准入条件。Luna只按20分钟节奏等待，学习、分析、修复和启动由主任务负责。

## E140完成，E141正式训练结果

E140全部1536家庭6144条原路线完成终局／状态／RNG重放，产生6144个首卡样本和92038个后续状态，合计98182行。主任务复核阶段退出、清理、全部证明哈希、原始终局目标及保留动作，故障0。新增游戏、MCTS为0。[数据结果](e140-trajectory-value-result.json)。

10:35上海时间由主任务启动E141控制器42678。两臂六个模型完成12000步，优化器耗时23.87秒。跨折父策略149胜，root_only150胜（新增46／丢失45，p=1），root_plus_later139胜（新增40／丢失50，p=.342833）；后者较前者−11，p=.184850。两臂学习门槛失败，不能据此采用新模型。完整3072次原生选择核验正在进行，完成证明与主任务复核另行追加。[拟合阶段结果](e141-trajectory-value-fit-result.json)。

root_only的三个拟合集分别达到170／193／199胜，等于各自已测首卡分支中每家庭取最优的上限；这表示每个有赢法的训练家庭能选到一个赢法，不表示每个分支的概率预测正确。加入后续状态时分别为164／182／191。跨折没有对应收益，未建立“多加训练步数就能解决”的依据。

原1536家庭中，首卡四选项的事后最优只有281胜，233家庭有胜负不同的选项。这是此批数据、固定后续父策略下的范围上限，不能外推为全游戏或总体上限，但它不能支撑在该范围内追求50%。后续方法需要处理贯穿全局的策略与学习信号，停止该首卡范围内的参数网格和扩采。
