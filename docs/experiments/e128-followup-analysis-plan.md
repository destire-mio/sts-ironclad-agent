# E128 复盘与 E131 条件实验设计

登记日期：2026-09-21。状态：历史结果分析和实验设计完成；E131 未启动。Luna 跟进当前 E127/E128 采样、审计和已登记训练流程，观察间隔至少 20 分钟；主任务负责实验问题、结果解释和下一轮选择。当前流程及冻结文件不因本设计变化。原版差异排查维持暂停。

## 从完成的实验中能得出什么

目前证据支持“训练中的收益没有转移到其他种子”，也支持“遗物与选牌存在组合收益”。数据数量、表示方式和决策范围各有疑点，没有证据把问题归结为其中一项。下面每行只比较同一实验内部；不同引擎和种子的成功数不能连成增长曲线。

| 完成的实验 | 同组结果 | 对下一轮的约束 |
|---|---|---|
| E54，战斗搜索方式 | 同一批 1024 个新种子，34 → 68 个心脏胜局，完整确认通过 | 战斗能力曾影响整局结果；“使用 MCTS”不等于战斗最优。当前沿用采用的搜索方式和预算，不能将训练失败归责于局外网络一个因素。 |
| E60，首幕 Boss 遗物偏置 | 同一批 1024 个新种子，83 → 112 胜，完整确认通过 | 少量有完整续局监督的参数曾带来可推广收益；扩大网络不是默认下一步。这是历史引擎成绩。 |
| E69，情境化遗物选择 | 拟合 156 → 221/1536；标签留出 46 → 25/512。拟合成绩达到所测首遗物组合的事后最好结果 | 网络能拟合这批动作收益，但留出退步。不能把训练拟合不足当作这次失败的解释；也不能据此单独认定数据少、参数多或表示差。 |
| E70，遗物与选牌组合 | 128 个拟合家庭：父策略 22 胜；事后单改遗物 28、单改选牌 31、组合 37；其中 3 个家庭只有两处一起改变才获救 | 组合效应有实测案例；37 是看完全部结局后挑选的数，不是神经网络成绩。 |
| E89/E95，冻结表示的联合读出 | 联合头 L2=.001：参与拟合的出现次数为 310 → 446/3072；按家庭留一折评估为 155 → 165/1536，新增 43、丢失 33，配对 p=.302，未过门槛 | 拟合收益大于跨家庭收益。3072 是 1536 个家庭各在两份拟合折出现，不能作为独立样本数。复用同一配方、增加同批曝光没有获得支持。 |
| E96，直接拟合相对父策略的胜负差 | 同一 1536 家庭的三个联合配置为 141、134、148 胜，父策略 155 | 该表示、目标和预算下的替代回归没有解决问题；不重复这组三档回归试验。 |
| E15，第一幕过幕奖励 | 同一 512 个开发种子，到第二幕 232 → 238，心脏 4 → 0 | 更容易过第一幕不能代替打赢心脏。新实验使用完整心脏结局，不将层数或过幕数作为成功标签。 |

证据入口：[E69](e69-contextual-relic-result.json)、[E70](e70-joint-coverage-result.json)、[E89](e89-joint-refresh-result.json)、[E95](e95-readout-diagnosis-result.json)、[E96](e96-paired-advantage-result.json)。E15、E54、E60 的完整结果与原报告哈希见[总账](../ironclad-experiments.md)第 26、62、68 节。E69/E95 的原始报告与完成证明、E96 的完成证明在本次复盘中与公开摘要哈希匹配；没有重新运行这些实验。

当前 E121 来源的 4608 个拟合家庭中，1006 个在第一幕死亡，1138 个到达第四幕，487 个打赢心脏。当前两个学习点是“首幕 Boss 遗物 → 第二幕第一场战斗后的最后一份选牌”，因此不能改变这 1006 个前置死亡。若只改第四幕，保留前面路线，所测拟合集的上限是 1138/4608=24.70%。前面的选择可以改变这个上限；这组统计没有证明当前两头的上限低于 50%，也没有区分构筑、路线与战斗的责任。见[当前来源分布](e122-fit-failure-profile.json)。

## 当前 E128 要解决的问题

在相同父模型、192 维冻结表示、两处决策和每臂 1000 次全批更新下，比较 1536 与 4608 个拟合家庭；两臂共享 1024 个标签留出家庭，另有 512 个自然开发家庭。完整现有流程交给 Luna；主任务不读取中途标签筛选方案，也不接替采样观察。

1. 两臂最终模型及完整证明产生后，按原协议比较各自相对父策略的新增胜局、丢失胜局、配对检验和执行故障。只有扩大组相对小组也通过预设净增与检验，才能说本轮增加独立家庭有效；不能比较两个不同分母的拟合胜局数。
2. 使用[已准备的范围诊断](e128-scope-diagnostic-sources/diagnose.py)，复用完整树，不采新游戏、不更新权重。将失败分成“没到可修改节点”“所测组合都输”“组合中存在胜局而模型没选中”。这项诊断在完整训练及留出核验后运行；不替换原有采用门槛。
3. 若扩大组通过所有开发门槛，主任务审核该候选和后续验收方案；不将 1024 个已用于比较的标签留出家庭重新称为未见验收集。若没有候选通过，保留父策略，启用下面的 E131 条件方案。

E89 所测两节点树的事后最好结果为 347/1536，不能迁移成 E121 的上限。E128 的事后树结果也不等于公开状态可预测的收益：模型在选遗物时看不到未来发出的牌。它用于判断采样范围与未学到的空间，不作为可部署的策略。

## E131：提前一个选牌机会，是否提供新的心脏胜负差异

执行条件：E127/E128 现有采样、审计、训练和全部已登记验证完成；没有候选通过完整开发门槛；父模型与 E121 引擎身份保持下列值。若条件不成立，本方案保持未执行状态，主任务根据新基线登记后续问题，不能套用旧标签。

这轮是 128 个已知拟合家庭上的范围诊断，没有优化器更新或新种子验收。它比较两个具体范围；选牌时间和两次决策的先后同时改变，不能将差异单独归因于某一个变化。

| 组别 | 可改变的决策 | 数据来源 |
|---|---|---|
| P，父策略 | 无 | 复用 E122/E129 的完整自然轨迹 |
| A，现有范围 | 首幕 Boss 遗物，随后第二幕第一战的最后一份选牌 | 完成后复用 E127 的相同家庭树与审计证明 |
| B，提前选牌 | 第一幕第一战的最后一份选牌，随后首幕 Boss 遗物 | 新建独立目录采集，其他选择沿用同一父策略 |

**家庭选择。** 从 E122 的全部 4608 个 fit ID 中，以 `sha256("e131-early-card-scope-20260921:" + 十进制ID)` 升序取前 128 个，哈希相同时按 ID 排序。选择只读取角色清单；不按成功、死亡幕、是否到达节点或组合收益筛选。ID 清单保存在本地忽略的运行目录，公开记录其哈希。共同标签留出、自然开发和退役验收家庭不加入。前置失败和缺少合格节点的家庭保留在 128 分母内。

**干预合同。** 第一处沿用 E128 的最后一份选牌合同，将幕号改成 1：`act == 1`、`cur_map_node_y == 0`、奖励界面、剩余一份卡牌奖励，而且父策略此刻选卡、跳过或唱歌碗。其他奖励处理与较早的一份牌由父策略完成；新流程须从自然状态证明这次机会对应第一场战斗。枚举该机会的全部合法选卡、跳过与唱歌碗动作。每个分支从改变后的状态运行，现场生成首幕 Boss 遗物候选，枚举全部合法遗物与跳过。未到第二节点的分支保留真实终局。不能把原路线的 Boss 选项、状态或父策略动作移植到新分支。

父模型 SHA256：`cbeac10f84c7f719ec48405ceecd663442e76b66a92234f1b090e2cfc2acfef4`。引擎 SHA256：`2474227122164379f8158ade2835d623e9b66670998eee910ce213fa86a3833d`。每次 MCTS 8000、Boss×3、重规划上限 256、游戏计时和候选生成继承当前冻结合同。每个状态只向模型提供当时可见的观察与合法候选，不输入种子、隐藏 RNG 或未来菜单。

**需要保存的对照。** 对每个家庭，分别统计父策略、事后只改第一张牌、事后只改首遗物、事后两处组合。所谓“只改牌”，是改变牌后让父策略在新的 Boss 状态选遗物；不是强制它选择旧路线的遗物。父策略牌加父策略后续必须复现原自然轨迹。A 与 B 各自的单项及组合结果都按家庭去重，不将分支数作为样本数。

**完整性与成本。** 新续局最多 4096 条，采集墙钟上限 4 小时，独立校验上限 1 小时，最多 8 个单线程工作进程，单局/进程保护 300/360 秒。这是资源上限，不是运行耗时估算。达到上限仍缺数据时记为未完成，不能裁剪合法候选、换家庭或把异常记成游戏死亡。启动前核对所需候选容量；合法候选较多时不能据此删分支。每条分支保存并独立核验动作、终态和 RNG；父策略控制匹配原来源；每个新增救回家庭按动作身份顺序固定一条胜局进行新规划复现和三钥匙、双 Boss、剑盾、心脏路线核验。记录采集、复用、审计和新规划的成本，不能把 A 的复用成本当作零采样成本去声称 B 更慢。

**这轮看什么。** 主指标是 B 中可救回、A 的全部所测组合却都失败的家庭数；同时报告 B 的胜负混合家庭数、第一幕原死亡中的获救数、必须两处改变才获救的数量，以及 A 可救而 B 不可救的数量。这里的“可救”指看过完整结局后存在获胜分支，不是模型会选中它。

采更多 B 标签的预算门槛在看结果前规定为：128 个家庭全部结算且故障为 0；至少 16 个家庭的所测 B 分支包含胜与负；至少 4 个家庭由 B 提供 A 没有的获胜分支，且按上述固定规则完成新规划核验。16/128 和 4/128 是下一次数据投入的工程筛选值，不是显著性检验、总体效应下界或模型采用门槛。未达到时不扩大这个固定范围的数据，也不通过重复抽 128 个家庭争取过关；不能据此否定全部第一幕干预。

通过该门槛后，下一张学习工作单才决定如何训练公开状态下的联合选择。目标要按“当前选牌概率 × 到达相应 Boss 后的实际遗物策略概率 × 心脏结局”求期望，不能把未来遗物的事后最好结果作为选牌收益。当前实现的顺序是遗物→牌，不能只改 `act` 字段就用于牌→遗物。新实现必须核对顺序目标、部署选择和来源控制，再划分独立家庭做学习与评价。E131 本身不会证明 128 个家庭足够训练，更不会证明加入一次选牌就达到 50%。

## 后续路线的取舍

优先把当前数据规模对照做完，再用上述小范围试验检验提前构筑的价值。若完整 E128 留出仍有大量模型错过的获胜组合，这说明存在“没有学到的空间”，不说明该空间都能从当时的观察预测。后续表示对照应在相同的完整树和独立家庭划分上检验，不能把采更多节点、换表示和改学习目标一起做，再把收益归给某一项。

不重跑 E89 原三档正则、E96 原回归组，也不把增加同批训练遍数当作本轮默认动作。冻结表示的探针表明部分 Boss/地图输入没有进入当前读出，但 E42 加 Boss 输入的完整开发曾是 47 对 48 胜；“补一个输入”没有获得成功保证。遗物切换曾改变 E89 的候选相对表示，因此“网络完全看不到遗物”也不符合已有探针。增加表示的具体工作单要说明新增信息及相同数据下的对照，不能用参数量代替问题定义。

本次交付只有分析、条件设计与种子角色冻结，没有新采样、训练、原版测试或候选采用。目标仍是冻结候选在 1024 个未参与训练、选择或调参的种子上至少 512 次心脏通关；需要另行完成全分母评估、置信区间和既有执行核验。
