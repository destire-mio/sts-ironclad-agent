# 第一幕非 Boss 死亡诊断：实验约定

基线固定为 c42 2000 局、v21、combat4r runtime-delivery、原 arms。

- 第一幕画像覆盖 2000 局原动作，重点 201 个非 Boss 败局。首轮单点预算诊断预设 N=40000 对 4N=160000，各状态各运行一次；不按哪一臂更好执行，不追加 2N 搜索挑结果。
- 预算诊断先覆盖全部 201 个致死入口，再补同遭遇、相近 HP 的第一幕存活对照。入场状态和 RNG 从原 prefix 恢复；1N 必须匹配原动作。基线已存在同树自适应扩展，N 指传入的首轮基础预算。
- 局外每规则每种子取首次可见条件命中，每根唯一替代；候选抽样按固定 SHA256 排序。主要验证目标为 Heart 全局胜负，第一幕生存另列。
- 所有反例、错误、终局不匹配保留。候选触发率从 2000 局原策略轨迹计数，外推只作发现集排序，不能当新种子收益。
- 同一根被多个规则命中时去重，保留规则归属；禁止同一根试第二替代后挑选。
- 最多 4 核、nice 10，native/BLAS 各线程上限 1，CPU affinity 0-3；仅本任务新目录写入。正式进程不更改。
