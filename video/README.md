# 项目介绍视频 · 动画

《杀戮尖塔》A20 铁甲战士 AI 项目介绍视频用的一套动画：12 段，每段可单独使用，统一画风。

- 1920×1080，60 fps，H.264（yuv420p，BT.709），无音轨
- 每段都从同一张深色背景淡入、淡出回这张背景，剪辑时可以直接拼接或单独插入
- 画面底部约 140 px 留给字幕，重要内容都在其上方
- 所有图形（卡牌、地图节点、心脏、钥匙、怪物等）都用代码重新绘制，不含游戏素材
- 评测数字留了占位，见下文“填写评测数字”

## 预览与渲染

需要 Node.js 18+ 和 ffmpeg。渲染用 Playwright 驱动无头 Chromium。

```bash
cd video
npm install                 # 字体（@fontsource）、qrcode、playwright
npx playwright install chromium   # 本机还没有 Playwright 自带的 Chromium 时运行一次
npm run preview             # 浏览器打开 http://127.0.0.1:8080/index.html，可选段、播放、拖动进度
npm run render              # 渲染全部 12 段和整片到 video/out/
```

渲染脚本的其他用法：

```bash
node tools/render.mjs --only s03,s11          # 只渲染指定段
node tools/render.mjs --fps 30                # 改帧率
node tools/render.mjs --still s04 --at 2.5,9  # 导出单帧 PNG 到 out/stills/
node tools/render.mjs --sheet s07 --n 12      # 导出缩略图拼板，检查节奏用
```

每一帧都是时间 t 的纯函数，预览和渲染画面完全一致；渲染时逐帧截取，不受机器快慢影响。
4 核机器上约 14 帧/秒，全部渲染约 15–20 分钟。成片在 `video/out/`（已在 `.gitignore` 中，不进仓库）。

## 填写评测数字

第 11 段的数字全部来自 `src/config.js` 里的 `EVAL`。值为 `null` 时显示占位（`XX.X%`、斜纹进度条）；
填上数字（百分比直接写数值，例如 `50.1`）后重新渲染这一段：

```bash
node tools/render.mjs --only s11
```

`hero` 是左侧大仪表盘（含局数和 95% 区间），`rows` 是右上三组对比，`stages` 是各阶段死亡率，`rules` 是右上角的评测规则标签。
填好后进度条、仪表盘会按数值动画增长，数字从 0 滚动到目标值。

## 画面里的数字

示意性质的数字（画面里已标“示意”或只用于说明机制）：第 3 段的选项分数、第 4 段各分支胜率、第 5 段的随机数位、
第 6 段价值表的升降箭头和对局滚动记录、第 7 段批量分叉的救回/丢失点数。

来自本仓库的事实：学生网络 `11195 → 384 → 1`、17 MB、sha256 前后缀（`student/README.md`）；
行为克隆用 3,000 局老师对局、两轮 DAgger（同上）；每次战斗搜索 32,000 次、Boss ×12（`sims32` / `boss12`）；
第 7 段的种子 3900012720 分叉（升级「武装」进心脏 37 血倒下，休息进心脏 53 血、剩 7 血获胜，见
`experiments-archive/local-runs/heart-research-20260929/paired-results.md`）；第 6 段的四条规则（`agent/baixi_rules.py`
与篝火休息规则）。第 5 段“5 张全部对上”演示的是机制；模拟器与原版的一致性状态仍是 INCOMPLETE（见仓库 README）。

## 目录

| 路径 | 内容 |
|---|---|
| `index.html`、`src/main.js` | 预览播放器；`?render=1` 时供渲染脚本调用 |
| `src/engine.js` | 时间轴、缓动、文字（含字体预加载）、背景、发光、面板、连线等基础绘制 |
| `src/icons.js` | 矢量图标：地图节点、心脏、钥匙、剑盾、骰子、锁等 |
| `src/widgets.js` | 组合部件：卡牌、神经网络、进度条、怪物、铁甲徽记、老师徽章 |
| `src/scenes/s01…s12` | 12 段动画，每段一个文件 |
| `src/config.js` | 帧率、仓库信息、评测数字 |
| `src/qr.js` | 仓库地址二维码（`node tools/make-qr.mjs` 生成） |
| `tools/render.mjs`、`tools/serve.mjs` | 渲染脚本与本地静态服务 |

## 风格约定

- 颜色固定分工：红 = 战斗 / 搜索，青 = 网络 / 学生，金 = 老师 / 重点，紫 = 随机数，绿 = 胜 / 一致
- 字体：思源黑体（Noto Sans SC）正文，思源宋体（Noto Serif SC）标题，JetBrains Mono 数字与代码，均为 SIL OFL 授权
- 每段开头标题先在画面中央出现，再移到左上角成为段落标题（`PART 01`…`PART 12`）
