# 升级开悟保留本回合免费效果

R24 修复升级开悟把免费牌改回 1 费的规则差异。木乃伊之手或液态记忆把高费牌的本回合费用变为 0 后，原版开悟把基础费用降至 1，并保留本回合的 0 费；模拟器此前把两个字段设为 1。玩家剩余 0 能量时，模拟器的合法操作列表因此缺少这张攻击牌。

候选来自原版 `EnlightenmentAction.update` 与 native `Actions::EnlightenmentAction` 的字段写入对照。原版对本回合费用和基础费用使用两个独立条件。修复删除基础费用分支中的本回合费用赋值，保留原有的 `costForTurn > 1` 降费路径。规则改动限于 `src/combat/Actions.cpp`；补丁接在 `exhume_selection.patch` 后，见[补丁清单](../alignment/enlightenment-free-manifest.json)。
