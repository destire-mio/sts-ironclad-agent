# 生成牌保留 X 费用

R25 修复羽化生成旋风斩时的费用差异。原版只把正基础费用的生成牌降为 0；旋风斩的基础费用和本回合费用保留为 X（字段值 −1）。模拟器此前对所有生成牌写入 0，产生两处费用字段分歧。

原版来源是 `Metamorphosis.use`、`Chrysalis.use`。两者使用 `card.cost > 0` 条件；native 共用的 `Actions::PutRandomCardsInDrawPile` 缺少这个条件。修复增加相同条件，改动限于 `src/combat/Actions.cpp`。补丁接在开悟修复后，见[分发清单](../alignment/generated-x-cost-manifest.json)。

费用字段参与异蛇油的随机化判断，因此验收包含生成、取牌、用牌和药水后续。修复前的普通检查器在生成牌时报告首处分歧，后续原版轨迹保留；报告不把首处之后的模拟器行为计为修复前比较结果。
